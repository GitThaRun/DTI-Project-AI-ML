## Overview

This project was developed collaboratively as a group project to classify images as **Real** or **AI-Generated** using deep learning techniques. The project explores transfer learning with a pretrained ResNet50 model and uses the CIFAKE dataset for image classification.

A Gradio interface provides an interactive way to upload images and view model predictions.

## Project Type

**Academic Group Project**

## Team Contributions

This project involved collaborative work across model development, image preprocessing, model evaluation, and interface development.


## Technologies Used

- Python
- TensorFlow / Keras
- ResNet50
- CIFAKE dataset
- Gradio
- NumPy, Matplotlib, and Scikit-learn

## Project Objective

To explore the application of deep learning and transfer learning in distinguishing real images from AI-generated images and to build an interactive image-classification application.


This repository contains the project code and resources for our collaborative work.
